## 可直接用于配音的表演提示

### 瑞克方向

成年偏老男性口语声线，音高以中低区为主，带适度沙哑和粗粝喉音。讲话像思考速度超过嘴巴：短促起句，快速解释，中途偶尔自我修正。保持强烈自信、轻微不耐烦和干冷讽刺，重读关键名词，结尾干脆下落。情绪爆发只出现在重点词，不要全程喊叫。保留可懂度；嗝声仅作为偶发独立表演，不要机械插入每句话。

### 莫蒂方向

少年男性声线，偏高音区、薄而有鼻音，带一点紧绷和气息。起句先犹豫一下，偶尔重复首词，然后把真正担心的部分快速说出来。疑问句尾上扬，惊慌时音高增加、节奏变急；恢复认真时让声音稳定下来。保留善良、焦虑与不服气之间的变化，避免全程结巴或尖叫。

### 中文改编原则

保留英语原声的情绪逻辑与对话节奏，中文仍按自然普通话重音断句。不要为了模仿连读吞掉关键知识点；同一个视频固定语言、版本和角色方向。
