## 几何检查及限制

在 Blender 以 BVH 表面检查 0 / 30 / 60 / 90 / 120°。二头肌与肱肌在这些检查姿态下不再存在相交表面。骨性起止点已投影到各自示意骨面。近端嵌入与共同肌腱汇合处仍存在简化交叠；未执行完整软组织接触计算，筋膜外壳也未做组织形变。详见 `MODEL-REVIEW.md` 与 `qa/geometry-audit.json`。

## 本次发现并修复

1. Blender 版本的材质节点名称差异：改为按节点类型查找，成功保存与导出。
2. 动画到 120° 后进入终止状态：改为明确按角度采样，反向屈伸可以继续。
3. 角度滑块被暂停处理写回旧值：先读取新值，再暂停和更新姿态；增加真实滑块断言。
4. 部分标记悬离骨面：按骨面投影设计足印，沿同一坐标重新建立肌腱/标记。
5. 二头肌与肱肌局部穿插、三头肌中部交叠：调整肌腹避让与远端汇合路径。
6. 展开后前臂末端接近视口边缘：调整默认取景距离。
7. 手机控制区离模型太远：把运动控件排到模型之后、结构详情之前。
