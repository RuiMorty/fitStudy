# 解剖与模型审核边界

## 可核对的事实与示意几何分开标记

2026-10-10 实际读取了 TeachMeAnatomy 的 [上臂肌肉](https://teachmeanatomy.info/upper-limb/muscles/upper-arm/) 和 [肘关节](https://teachmeanatomy.info/upper-limb/joints/elbow-joint/) 页面，并补充读取 [Kenhub 肱肌](https://www.kenhub.com/en/library/anatomy/brachialis-muscle) 核对肱肌前面远侧半起点及冠突/粗隆止点。已核对的文字包括：

- 二头肌长头起于盂上结节，短头起于喙突；经远端腱止于桡骨粗隆，并有腱膜连至前臂筋膜。
- 肱肌在二头肌深面，起于肱骨干远侧区域，止于尺骨粗隆与冠突（具体足印分区尚未建模）。
- 三头肌长头起于盂下结节，外侧头起于桡神经沟上方的肱骨后面，内侧头起于沟下方；远端连接鹰嘴。内侧头较深。
- 滑车—尺骨滑车切迹、小头—桡骨头为肘关节的骨性配对；屈伸与旋前旋后是不同运动自由度。

未以医学影像、解剖实测或专业人员签核验证任何网格。网页与结构数据始终显示「几何示意」。参考资料只用于文字事实核对，没有复制其中的网格、插图或整篇正文。

## 仍需解剖专业审核

| 项目 | 当前状态 / 审核内容 |
|---|---|
| 骨骼 | 原创程序化骨干与骨性标志；肩胛骨尤其简化为薄板、冈与突起。关节面曲率、鹰嘴切迹、髁间形态、骨干扭转和个体比例都未审核。 |
| 关节轴 | 以近似滑车/小头中心定义内外侧单轴。未实现携带角、瞬时轴迁移、软骨厚度、关节面滚滑、锁定机制或关节囊约束。0–120° 为样板演示范围，并非正常活动度测量值。 |
| 骨性足印 | 初始设计点投影到对应示意骨面；起点广面压缩为点。投影误差为零不代表真实解剖误差为零。需审核面积、方向与个体差异。 |
| 二头肌 | 两个肌头在远端汇合为共同腱；肌腱扭转、各头足印、长头囊内路径/结节间沟接触、肱二头肌腱膜尚未准确建模。 |
| 肱肌 | 宽阔起点与尺骨端的不同附着分区简化；冠突附着、肌内腱膜与不同神经支配区待专业复核。 |
| 三头肌 | 三头共用远端路径；真实腱膜层次、内侧头深部插入、鹰嘴滑移/滑囊未表示。肌头汇合处仍有相交面。 |
| 筋膜 | 固定单层上臂外包络，只验证独立显示/点击；无肌间隔、真实厚度或弹性。屈曲时肌腹可能穿出此固定示意外壳。 |
| 未覆盖结构 | 喙肱肌、肘肌、旋后肌、关节囊、韧带、软骨、神经、血管与全部前臂肌肉不在本次范围内。 |

## 形变与连接的实现

骨骼按刚体层级运动；尺桡骨保持旋后关系，肩胛骨与肱骨固定。肌腹和肌腱以附着坐标、共享汇合点和避让控制点生成曲线路径，截面沿路径渐变。肌腹截面半径按 `sqrt(初始路径长度 / 当前路径长度)` 近似调节，视觉上呈现缩短变粗、拉长变细。此规则不是组织体积或生理肌力的求解器。

Blender 每 5° 保存一组形态键，网页同步采样 GLB 的骨骼动画和所有形态键。非关键角度为插值，存在很小的弧线近似误差；浏览器测试单独检查了远端腱与运动骨性标记之间的误差。

展开使用每个对象独立的偏移，偏移在世界空间应用，再换算到其父对象局部坐标，避免尺桡骨随屈伸产生额外错误偏移。绿色虚线从肌腹端连接到对应骨性足印，表示关系而非新组织。共享肌腱仍为独立对象。点击复位将偏移严格置零，不累计位移。

## 穿插检查的结论范围

使用 Blender BVH 检查 0 / 30 / 60 / 90 / 120°，并在浏览器观察前、侧、后和深层视图。已修正二头肌与肱肌的局部表面穿插，以及三头肌外侧头与内侧头中部的交叠。

仍保留用于连接的近端骨面嵌入和共同远端汇合处的网格交叠。它们没有经过组织接触/压力求解；不能把样板称为「全角度无碰撞模型」。独立筋膜外壳也不参与碰撞响应。原始数字见 `qa/geometry-audit.json`，相交三角面数量不是临床指标。

## 扩展到全身的工作量估算

建议先把本样板送交解剖审核，冻结命名、足印、层级、动画与审核流程，再按关节区域分批扩展。不能只复制肘部参数覆盖全身。

计数口径：骨骼按成年典型 206 块作为清单起点；约 600–650 块骨骼肌是常见概数，左右侧、肌头、腱膜与独立肌腱再拆分后，会明显多于该数。最终工期应以冻结后的对象清单计算，不把「650 块肌肉」等同于「650 个网格」。

下表为**同一示意精度、独立可选、主要关节有教学形变**的粗估人周（1 人周 = 5 个工作日），含制作、复核与返工，不是性能或交付承诺：

| 工作 | 估计人周 |
|---|---:|
| 全身清单、左右侧与命名、参考资料、验收标准 | 2–3 |
| 骨骼与主要骨性足印 | 4–6 |
| 肌肉 / 肌头建模、层次与附着 | 10–16 |
| 主要肌腱、必要腱膜与示意筋膜 | 4–7 |
| 主要关节动作、肌腱绕行与形变 | 6–10 |
| 网页分区加载、选择、层级、移动性能与综合 QA | 4–6 |
| 合计 | **30–48 人周，约 7–11 人月** |

模型师、交互开发和解剖审核者组成 3 人团队，存在并行与审核依赖，日历时间可先按 **3–5 个月**规划。若提升到经过专业审核的高质量解剖资产、补齐所有足印/腱膜与复杂关节，粗略增加到 **50–80 人周（约 12–19 人月）**。医学影像级重建、全身生物力学求解、病理变化和临床认证另计；已有合法授权资产可减少建模时间，但仍需要拆分、绑定、再分发许可核对和验收。
