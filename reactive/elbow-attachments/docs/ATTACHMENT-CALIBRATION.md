# 起点校准记录 · 2026-10-10

## 为什么旧点会错

旧算法以肌头网格最高 0.5% 顶点的中心为起点候选，再投影到整块骨的最近表面。弯曲的长头腱最高处并不是腱的骨性起始处。源肌腱已到达关节盂上缘附近，橙色标记却位于肩峰。旧点距离长头近端腱表面约 5.9945 mm；此前检查仅证明该点贴骨，未检查近端腱，因而漏掉了问题。

此数值是当前模型内部的距离，不是患者测量精度。

## 本轮方法

1. 在来源骨面和软组织间进行前、侧、后及斜向观察，显式指定候选区域与代表位置，保存到 `attachment-landmarks.json`。这一步是模型作者的定位，未获得解剖专家签核。
2. 标记仅投影到指定候选区域；输出前断言投影没有离开区域。不会再用网格最高处替代起点。
3. 在区域内，筛选源软组织邻近骨面的部分。距离骨面不超过 0.5 mm 且位于区域内部的顶点固定到骨面；到 4 mm 的距离带及区域边缘平滑过渡回原形变。阈值属于几何适配参数，不代表真实组织厚度或足印边界。
4. 对肱肌及三头肌增加局部骨干侧向约束：以源位置对应的肱骨切平面限制内穿，靠近肘部逐渐解除，允许远端腱转动。这是防止线性插值穿过骨干的几何近似，不是组织碰撞或生物力学求解。
5. 骨面接触候选区以独立标注网格保留，显示时仅向外偏移 0.12 mm 防止重叠闪烁。色块在 1.2 mm 的接近阈值内取样，所以不应理解为每个色块点都与组织表面焊接。
6. 在 Blender 中保留 `Origin_fixed_to_bone` 顶点组、`08_Attachment_regions` 集合及 `ATTACHMENT_LANDMARKS` 文本。网页显示选中肌头的候选区域；起点检查临时隐藏遮挡骨、降低软组织不透明度。

## 六个候选部位

| 肌头 | 候选区域 | 未确认的边界 |
|---|---|---|
| 二头肌长头 | 关节盂上缘、盂上结节邻近骨面 | 上盂唇未建模，完整腱唇附着未确认 |
| 二头肌短头 | 喙突尖邻近骨面 | 与喙肱肌共同腱的分区 |
| 三头肌长头 | 盂下结节邻近骨面 | 完整近端腱足印 |
| 肱肌 | 肱骨远侧前面代表区 | 起点的完整边界、肌间隔附着 |
| 三头肌外侧头 | 肱骨后面近侧代表区 | 桡神经沟上界及肌间隔附着 |
| 三头肌内侧头 | 肱骨后面远侧代表区 | 桡神经沟下界及完整宽起点 |

## 仍需专业审核

色块均维持 `candidate-pending-anatomist` 状态。需要审核者在多视图中确认骨性标志、完整附着边界和腱的走行，修订坐标文件后重新生成并执行几何检查。二头肌长头应进一步补足上盂唇、关节囊关系；宽起点要补充肌间隔。不得因几何误差很小自动改为“解剖准确”。

本轮没有重建全部远端止点，没有消除所有肌间穿插，没有引入生理肌力或接触求解。它修复了明确的起点标记错误，并提供可编辑、可核对的起点区域与局部几何连接。
