# 精细版实现

数据流：`sources/*.stl → build_studio.py → .blend / .glb / structures.json → GLTFLoader → 关节曲线 + 相邻形态键 → WebGL`。

源网格身份由 `sources/provenance.json` 映射。清理/降面、肌腱分区、纹理与动画都在 Blender 中生成，输出可编辑源文件，不依赖网页临时画出假模型。

标准单位为米。Blender 局部 `[x,y,z]` 导出为 glTF `[x,z,-y]`。骨骼保持刚性；肌肉与肌腱使用 24 个形态目标，网页逐角度插值相邻两组位置与法线数据。起止点、肌腹端点使用同步导出的动画空对象。

Three.js 0.180.0 运行库本地保存。物理材质包含纤维颜色/法线/粗糙度与胶原法线；方向光形成实时接触阴影。暂停时恢复较高像素采样；播放时使用较低采样并间隔更新阴影，保留同一份模型和材质。

浏览器测试使用真实鼠标/触摸事件检查画布拾取，并单独验证角度滑块、动画往返、结构显隐、展开精确复位和足印坐标。手机是 Chrome 移动视口触控仿真，不代表实体 Safari/Android 验收。
