# 精细版的精度、适配与待审核事项

## 已经改善的内容

4 块骨及 6 个肌头的基础轮廓直接来自 BodyParts3D 3.0 的对应独立 FMA 网格。本次清理 STL 重复顶点与法线、轻度平滑、保留轮廓的降面，并基于原始骨面配准肌肉足印。原始 STL 随项目提供，可以逐个比较。

相对于旧样板，肩胛骨不再是三角薄板，骨端不再由简单球体组合，肌腹不再是统一纺锤。可看到肩胛骨凹面和骨性标志、肱骨骨干与端部变化、尺桡骨的不同轮廓，以及肱肌/三头肌的宽扁和包覆关系。

「数据库形态」只说明基础几何来源，不能自动等同于本次改动全部经过解剖审核。原始数据库也存在相邻肌肉交叠。本次用毫米级配准位移减少交叠，保留形状特征；不声称所有表面均是原始测量坐标。

## 本次适配

- 原始源坐标为毫米，右侧 X < 0、前方 Y < 0、Z 向上。平移到选定肘轴附近后转换为米、翻转 X/Y，再绕 Y 旋转 0.215 弧度使上臂更适合观察。网页采用 glTF 标准 Y-up。
- 在网格的细长区域分离两条二头肌近端腱、二头肌远端腱、肱肌远端腱和三头肌长头近端腱；三头肌三个头的远端片段组合为独立的共同肌腱对象。分区平面与过渡区域是本次选择，尚未专业审核。
- 足印标记投影到对应骨面；近端广泛起点仍压缩为区域代表点。
- 用共享形变场驱动原网格，不把肌腹换成曲线管。肌肉和相邻腱区使用相同场；每 5° 导出一组形态键。网页只向 GPU 提交当前相邻的两组形态键，并同步变形法线。
- 纤维颜色/法线/粗糙度、肌腱胶原细节和肌腱交界处的窄色彩过渡属于艺术化可视化，不是组织显微重建。
- 展开时用随动画变化的肌腹端标记连接到骨性足印。复位直接清零偏移，避免累积误差。

## 尚待确认

| 项目 | 尚未完成的审核或模拟 |
|---|---|
| 个体与数据精度 | 单一男性参考数据；未做医学影像逐层复核，也不覆盖个体、年龄和性别变化。 |
| 骨性关节 | 轴位置按模型配准选择，尚未测定瞬时旋转轴、携带角、软骨厚度与接触滚滑。0° 为本样板配准姿态。 |
| 肌肉 | 源数据本身及适配运动仍有局部交叠，特别是附着/汇合区域。没有全组织碰撞、压力或有限元求解。 |
| 肌腱 | 本次从解剖网格分区；长头囊内走行、结节间沟滑移、足印分区、腱膜和三头肌各层腱片尚待审核。二头肌腱膜未完整纳入。 |
| 运动含义 | 形变只展示无外负荷、交替主动屈伸的教学情境。无法据此推断真实激活、肌力、力矩、肌束长度或训练负荷。 |
| 筋膜 | 按配准后肌肉包络生成的独立示意层；无真实组织厚度、肌间隔或材料力学，高角度也没有求解其贴合形变。 |
| 未纳入的结构 | 关节软骨、韧带、关节囊、血管、神经、喙肱肌、肘肌及前臂完整肌群。 |

骨面足印距离和网页动画误差仅证明这份模型内部的一致性。不得把「0.05 mm 以内」等内部检查结果当作真实解剖测量精度。

## 全身扩展

本轮验证了可追溯解剖网格能接入同一套独立对象、显隐、展开、足印和形变流程。全身可继续利用许可兼容的数据，但仍需逐区域处理结构清单、肌腱分区、关节轴、多自由度运动、层次交叠、分区加载和专家审核。仍建议以 **7–11 人月、3 人团队约 3–5 个月**作为同等范围的粗略初期规划；冻结全身清单后再估算。完整临床级模型或全身生物力学求解不包含在该估计内。
