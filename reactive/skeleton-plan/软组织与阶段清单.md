# 后续软组织与阶段清单

本表为前4类功能所需的关键依赖，不是全身全部肌肉、韧带、筋膜的最终逐对象名录。进入某部位制作前，应将该行展开为逐结构清单，每项具有ID、起止/边界、关联骨与关节、来源及审核状态。

| 颈椎 | 寰枕/寰枢稳定结构，C2以下椎间盘、关节突软骨与囊 | 颈深浅层屈伸、旋转肌群及其腱膜 | 颈筋膜及相关肌间界面 | 点头、转头、屈伸 |

## 阶段顺序

### A：来源与全套装配准入

逐骨源映射 → 同源/注册核查 → 全身原始装配 → 薄骨片、左右侧与关键关节检查。未通过前，不进行206块高精资产的批量美化。

### B：完整骨架交互

206骨的独立对象、中文结构树、区域加载、点击拾取、显示层级、单块隔离、区域/逐骨展开与精确复位。拇指和拇趾籽骨列为对应功能阶段的必要扩展。

### C：代表性骨架运动

先用肩—肘—桡尺、髋—膝、踝—足验证运动系统，再扩展脊柱、手等。此阶段允许骨架运动示意，但必须注明尚未补齐的软骨和稳定结构，不以裸骨接触证明生理关节运动。

### D：按部位完成软组织闭环

选定一个区域，完成其必要关节组织、肌腱、肌肉及筋膜，再同时检查：附着、滑动、肌腹形变、邻近碰撞、解释文字和网页操作。不要先批量做完所有肌肉外形，最后才发现统一运动方法不成立。

每个区域依次经过“源数据可用 → 静态配准 → 关节运动 → 软组织运动 → 网页验证 → 解剖审核”状态。每一项分别记录，不能用浏览器功能检查代替解剖审核。
