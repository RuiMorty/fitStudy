# 同源与装配准入

> 更新：以下初始来源说明已由[2026-10-12资源核对](source-audit/核对结论.md)补充。最新逐文件、覆盖和关节初筛状态以该报告为准。


## 候选来源及现有证据

优先评估现有样板使用的 BodyParts3D / Anatomography 3.0（20110915）同一数据集及注册基准。现有来源记录固定镜像提交为 `f0eeb6e843380cfe6b83797cf8c3e1af74de5e61`，来源由 DBCLS 提供；镜像地址为 <https://github.com/Kevin-Mattheus-Moerman/BodyParts3D>。

本轮只读取并核对了既有 `elbow-attachments/sources/provenance.json` 中四块骨的原始STL与记录哈希：右肩胛骨、右肱骨、右尺骨、右桡骨。没有在本轮获取或核实该提交对206块的完整覆盖，也没有确认所有单骨可分离程度、模板身份与相互配准质量。候选来源不是已通过准入的来源。

## 不可绕过的准入项

| 编号 | 检查 | 必须留下的证据 | 不通过时 |
|---|---|---|---|
| S1 | 同一数据集、版本、发布包与注册基准 | 数据集元数据、固定提交/发行包、模板/注册信息、引用与许可证原文 | 暂停批量导入 |
| S2 | 206个核心ID逐一映射 | 源结构ID、语义层级、左右侧、原文件、哈希；标明单文件/多文件/需拆分 | 明确缺项，不拿相似骨充数 |
| S3 | 源坐标一致 | 原单位、轴方向、全局变换矩阵、原始完整装配截图与尺度检查 | 不能逐骨单独归一化 |
| S4 | 生物学身份/配准关系可说明 | 若是参考图谱而非单一个体扫描，记录原图谱如何注册，不能描述为同一个真实受试者 | 数据不足则标记待核对 |
| S5 | 关键关节面匹配 | 关节面覆盖、方向、局部尺寸、间隙/重叠、左右比较，带位置与截图 | 记录源偏差，禁止任意缩骨掩盖 |
| S6 | 源拓扑能支撑独立骨结构 | 连通域、孔洞、法线、薄骨片、颅缝及小骨检查 | 修补/拆分保留原件、操作记录和待审状态 |
| S7 | 许可与派生分发 | 原始署名、许可文本、派生模型/截图/源码的适用范围 | 未确认允许的用法不得作为可再分发交付源 |

同一套图谱不自动等于无穿插，也不自动等于能运动。关节软骨及其他组织缺失时，不能将所有骨间空隙填满，也不能让裸骨表面直接贴死来伪装关节配合。

## 统一坐标与保存方式

- 保留只读的原始源文件及源空间坐标。全身统一换算为米，统一坐标轴；具体矩阵在获取源集后确定，当前不填猜测值。
- 不继承肘部样板为局部展示使用的平移/旋转作为全身未经验证的装配基准。
- 作者场景保存每块骨的原始装配变换，另存每个关节相对于参与骨的局部坐标系。骨对象原点与关节中心允许不同。
- 显示层级、解剖区域、关节连接图分开。不要为了树状父子结构方便而删掉多骨耦合关系。
- 保留高精度主模型；网页LOD是派生文件。每级LOD对应同一语义结构，不能更改骨的尺寸或装配位置。

## 缺项与修模

先查同一源集的结构分组或父子对象，确认不是被并在上一级网格内。必要拆分应沿解剖边界处理并复核。确实缺失时，优先换成一套覆盖充分、许可合适且可证明统一注册的数据集，或在同一模板中依据可靠参考补建并单独标记“派生补建、待审核”。

不把另一来源、另一体型、镜像复制的骨直接标为该侧原始同源骨。不得靠分别缩放、随意拉伸关节面解决拼装问题。任何非统一形态调整都要记录原始几何、调整理由、邻近结构影响及复核状态。

## 批次来源清单必填字段

`source_set_id / dataset_version / reference_template / registration_evidence / source_structure_id / original_file / sha256 / source_units / source_axes / global_transform / derived_operations / license / anatomical_review / assembly_review`。

目前缺少的字段保持空值及待核验状态；不以默认零值、单位矩阵或“准确”标签代替核验。
