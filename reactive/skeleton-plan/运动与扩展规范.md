# 运动与扩展规范

## 结构数据

每块骨的稳定ID贯穿Blender、GLB、结构数据与点击拾取；显示名称可以修改，ID不随名称或文件路径改变。一个结构可有多个网格块，但每个可见网格必须能反查唯一语义结构。网页结构计数按语义ID，不能直接数Mesh。

`bones-206.json` 已预留原始装配变换、来源ID、关节连接引用和骨面标志区域引用。目前未获得的数据保留null/空列表，不代表不存在或已经校准。

必须区分：`解剖区域分组`、`刚体运动/耦合约束图`、`展示用父子层级`。下颌的双侧关节、骨盆环、肩带和桡尺关系都不能由一条简单父子链完整表达。

## 关节定义

每个真实关节或功能连接最终需具备：

| 字段 | 含义 |
|---|---|
| involved_structures | 参与的骨、软骨、关节盘等结构ID |
| frames_on_bones | 固定在各参与骨上的局部关节坐标；不是全身坐标的临时数字 |
| articular_regions | 对应的关节面区域与审核状态 |
| motion_model | 固定、近似铰链、旋转、滑动、多轴、耦合或功能性滑动 |
| axis_or_path | 固定轴或随姿态改变的轴/轨迹；附依据和适用范围 |
| range_profile | 主动/被动、姿势、人群、角度约定及参考来源；不使用一套全身通用极限 |
| coupled_constraints | 其他关节/骨的同步关系，明确唯一驱动者及被约束状态 |
| contact_dependencies | 软骨厚度、关节盘、半月板、韧带等必要条件 |
| reviewed_poses | 通过几何及人工审核的姿态、连续运动范围和未解决项 |

清单中的205条记录混有真实关节与连接组。连接组在实现前必须细分必要的关节面及内部约束；不得将组内所有骨整体锁死，也不得对同一自由度重复施加相互矛盾的动画。图结构允许闭环，实际求解/耦合方式在具体关节原型中验证。

## 优先验证的复杂运动

- 肩：胸锁、肩锁、盂肱和肩胛胸壁共同运动。肩胛沿胸壁滑动，不能仅把肩胛骨挂在肱骨上；肩胛肱骨节律不预设为固定比例。
- 肘/前臂：肱尺屈伸、肱桡接触、近远侧桡尺旋转分别建模并耦合。旋前旋后时桡骨相对尺骨运动，不能让两骨始终锁成刚体。
- 脊柱：逐节段建模椎间盘与关节突关系；C0—C2具有特殊结构，不套普通椎间盘方案。
- 骨盆/髋：骨盆环约束与髋多轴运动并存。记录骶髂微动和耻骨联合关系。
- 膝：胫股滚滑、伴随旋转与髌骨轨迹共同验证；不用一根固定轴替代所有角度。
- 踝足：踝背屈跖屈与距下、横跗、足弓/前足耦合；拇趾运动需相关籽骨、肌腱和足底腱膜。
- 手：拇指对掌、各腕骨/腕中活动、掌指和指间联动分开定义；肌腱滑车会影响后续路径。

## 为肌肉、肌腱与筋膜预留

1. 附着使用骨面区域，而不只有一个点：`region_id / bone_id / anatomical_label / boundary / reference_surface / representative_point / surface_normal / source / review_status`。宽起点必须记录范围。
2. 附着区域在高精参考表面上标注。网页LOD变化时保留对应关系并复核；不能依赖降面后会变化的裸顶点序号。
3. 肌头、肌腹、肌腱、腱膜可独立命名并组合为肌肉。各对象保留自己的来源、几何与审核状态。
4. 记录跨越关节、静止路径、附着区域、绕行面/滑车、与邻近组织的滑动界面。肩位置对三头肌长头的影响不能在全身阶段忽略。
5. 筋膜按浅筋膜、深筋膜、肌间隔、支持带/腱膜等类型分区；不将一个外包络当作全身真实筋膜。
6. 肌腹形变基于整体路径变化并兼顾宽起点约束、横截面变化和肌腱连续性。不能只拉末端，也不能为了无穿模而牺牲整块肌肉外形。
7. “肌肉颜色/标签”只表达选定教学情境，不能暗示系统计算了真实激活或肌力。关节运动方向本身不足以判断某肌肉是否主动收缩。

## 展开与复位

- 保存统一装配姿态与当前关节姿态；展开是独立显示变换，不能写回解剖装配或运动数据。
- 支持全身按区域展开、区域内逐骨展开、单块隔离。全身206块同时放射展开不是唯一展示方式。
- 默认在暂停状态展开；若允许展开时播放，必须保持运动姿态与显示偏移分离，连接引导线跟随实际附着关系。
- 复位清零显示偏移并恢复精确姿态；相机复位和模型聚合是两个独立操作。
- 多次往返展开、切换部位、隐藏/隔离、播放暂停后均不得出现累计偏移。

## 分级验收

| 层级 | 实际检查 | 不能由该项证明的内容 |
|---|---|---|
| 清单 | 数量、唯一ID、左右对、引用、来源覆盖 | 模型解剖准确 |
| 静态骨架 | 全局尺度、配准、关节面、小骨/薄片、完整性 | 能正确运动 |
| 运动 | 骨的相对位姿、轴/轨迹、极限、正反向连续播放、接触 | 肌力或医学精度 |
| 软组织 | 全路径/肌腹变化、附着稳定、腱连续、骨面与组织间碰撞、正侧后多视角 | 真实生物力学计算 |
| 网页 | 真实拾取、深层查看、精确复位、按区域加载、桌面及手机流畅度 | 解剖审核完成 |

全范围采样包含关键帧之间的姿态；穿插检查覆盖顶点、面及必要的相交/距离判断。取点方法、阈值和排除区域事先记录。既有错误案例作为反例，确保检查能发现真实问题；数字通过还必须看连续运动与整体轮廓。

网页采用按区域加载、LOD及资源释放，避免全身高精骨骼、软组织一次性常驻。保存实际GLB体积、可见三角面、设备、帧率及交互延迟；实体手机验收不能用桌面触控仿真代替。具体性能门槛在第一批骨架原型测量后确定，不承诺未经验证的60 FPS。
