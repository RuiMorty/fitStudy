## 本次确认的功能范围

1. 点击识别、中文搜索、隐藏、隔离、按区域/逐骨展开与准确复位。
2. 骨架关节运动演示，包含关节运动约束与多关节耦合。
3. 关节间隙、稳定结构及软组织关系教学。
4. 肌肉/肌腱起止附着与运动时的形态变化。

真实肌力、关节受力及有限元计算不在本阶段范围。屈伸方向不能直接等同于某肌肉有无激活；被动观察和主动运动示范须明确情境。

## 开始批量建模前必须通过

- 完整核对同一源集的结构覆盖、左右侧、源ID、文件哈希和许可。
- 证明其坐标/模板基准一致；同一网站、同一格式、同一版本号本身均不足以证明配准一致。
- 检查原始整套装配与关键关节面匹配，不分别缩放骨头来“拼得上”。
- 对缺失的骨及籽骨制定同一模板内的补建办法和审核记录；无依据时记录缺失，不混用其他体型资产冒充同源。
- 肩带、肘与桡尺、髋膝、踝足至少完成运动可行性验证，才扩展批量高精模型及软组织。

最新核对已取得199块核心骨及两组足部籽骨的源文件；尾骨分界、听小骨、拇指籽骨和关节面配合仍待解决。详细状态见资源核对结论，不能声称“全套同源匹配已保证”。
