# 骨骼资源核对结论 · 2026-10-12

**结论：BodyParts3D 3.0可作为统一坐标的骨架来源候选，但尚不满足“206块独立、关节配合已核验”的批量制作准入条件。** 本轮只获取和检查源资源，没有生成、修补、拆分或替换现有模型。

## 同源与原始装配

- 全部本轮下载文件固定到同一镜像提交 `f0eeb6e843380cfe6b83797cf8c3e1af74de5e61`，对应上游记录的BodyParts3D 3.0（20110915）。索引、组合关系、README、许可和坐标说明也来自这一提交。
- 镜像README称其为单个男性参考模型；这是上游说明，不代表我们取得了原始影像并独立验证其受试者来源。图谱中各结构的构建/配准依据仍需保持来源追踪。
- 同提交坐标图明确标示毫米单位，左X正、右X负，前Y负、后Y正，Z随身体向上增大。未逐骨缩放、重新归零或移动。
- 原始骨架范围约X −324.651至323.315、Y −230.845至11.352、Z −4.171至1638.220毫米。少量足部Z低于坐标图所说的正值，照实记录，没有偷偷抬高骨头。
- 已找到的83对左右骨全部符合X方向侧别排序；包围盒对角线左右比例均处于0.8—1.25的粗筛区间。该区间只用于发现明显比例错误，不是临床对称性标准，也不证明左右分别来自独立扫描。
- 从统一坐标直接投影可组成连贯骨架，未见明显漂散或整体比例错位。此观察不能替代每个关节的精确装配审核。
- 现有肘部样板的4块原始骨文件与本轮下载同名文件的SHA-256完全一致。

## 网格与关节问题

所有203个文件符合二进制STL长度和三角面计数，坐标均为有限数。按完全相同坐标焊接后，边界边和大于2面共用的非流形边均未检出。**这不等于已经完成全网格自相交、体积有效性或解剖精度检查。**

需复核的碎片：右拇指近节指骨（主体1360面+8面小片）、右小指远节指骨（464+2面）、右第五趾远节趾骨（260+14面）。本轮没有自动删除碎片。较小足趾骨的面数仅约数百，来源说明该资源由95%降面版本转为STL；能展示不等于关节面精度足够。

对双侧肩、肱尺、肱桡、髋、胫股、髌股、胫距、腓距，共16对骨面作静态BVH初筛：

| 发现 | 结果 | 意义 |
|---|---|---|
| 左髋骨—股骨 | 204对三角面相交；抽样局部法线判定最大内穿约0.80毫米 | 原始同源骨也存在配合问题，需核对关节面/分割精度 |
| 左胫骨—距骨 | 22对三角面相交；抽样内穿约0.046毫米 | 微小重叠，后续应结合软骨与足踝模型审核 |
| 右胫骨—距骨 | 28对三角面相交；抽样内穿约0.096毫米 | 同上 |
| 其余13对本次检查 | 未检出三角面相交 | 只代表所查静止姿态和算法结果，不代表运动时不会穿插 |

抽样距离不是完整接触面间隙，更不是软骨厚度。尚未检查全部关节、所有颅缝、动态轨迹或软组织接触；没有设定可据此直接通过的解剖公差。

## 准入决定与后续顺序

1. **同一版本/统一坐标证据可用；全套覆盖与关节配合准入未通过。** 保留所有原始源文件，不立即批量加工为“已准确”的206骨成品。
2. 优先核实骶尾分界和足部籽骨归属，整理需要拆分的区域与参考依据。
3. 对听小骨及拇指籽骨，继续核查官方同源资料的覆盖。若需评估另一发布版本，应整套评估其注册基准与质量；不得把另一版本的小骨直接拼进当前骨架并声称同源匹配。
4. 对左髋、踝及细小关节面确定修模/更高精源方案，再用肩肘、髋膝、踝足做运动可行性验证。高分辨率数据是否存在且可用，当前未核实。
5. 只有在来源覆盖和装配方案确定后，才进入可编辑Blender场景、网页GLB与关节绑定制作。
