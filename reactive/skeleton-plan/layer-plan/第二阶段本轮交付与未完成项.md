# 第二阶段：全身韧带接入、椎间盘修复与内部视图

2026-10-12。**第二阶段整体仍未完成。** 本文件记录本轮真实交付和剩余限制，不把候选提取数当作完成率。

## 本轮实际交付

- 新接入 286 个韧带／骨间膜源对象，覆盖肩肘、腕手、髋膝、踝足、脊柱、胸廓、骨盆及部分颅颈连接。加上既有 4 个，共 290 个该层候选。
- 来源为同一 Z-Anatomy Startup.blend；未移动源顶点、未缩放配准到其他骨架。名称翻译和源父级目录映射保存在 research/ligament-library-mapping.json；区域关联骨不是精确起止点。
- 其中 18 个原网格存在多面共用分叉边。本轮将分叉共边拆成位置重合的边，保留全部原面及顶点坐标，不填充或删去表面。它们单独标记“拆缝候选待审核”；此处理只使拓扑适合显示，不证明真实组织存在这些接缝，也不构成解剖修复完成。
- 29 个其他有面对象单独列入排除表：附着标记、眼部／喉部结构、后续筋膜相关结构等。髌韧带目前仅找到起止标记，未把标记冒充完整韧带。源库中无左右后缀的尺豌豆韧带仍按未定侧目录处理，不推断其精确侧别。
- L1–L2 椎间盘局部拓扑修复候选已接入。去除缺陷邻域 20 个面（合计约 1.242 mm²）后，修补 3 个局部区域，最大跨度约 2.645 mm；未移动保留顶点。输出无边界边、分叉边或孤立线段。修补形状仍待审核，不是健康椎间盘的医学重建。
- 23 个源髓核可通过“髓核内部视图”显示，启用时隐藏完整椎间盘，关闭时恢复，避免重叠。没有生成或声称已经生成独立纤维环。
- 增加腕、踝与后足、脊柱、胸肋连接入口。局部显示补入候选关联骨，避免单独展示韧带时遗漏关联骨；腕踝聚焦关节区域。

## 为什么仍不能标记第二阶段完成

1. 关节软骨主要仍是骨表面的材质分区，没有经核对的实体厚度。569 条记录只有相关骨材质线索，28 条已有分区候选；需要逐关节确定边界和厚度依据，不能统一挤出。
2. 当前源库名称检索中的 synovial 有面对象只有手指腱鞘，不能冒充关节滑膜。滑膜模型尚未接入。以现有登记类型计算，116 条明确含滑膜关节类型的记录没有滑膜模型，其中 38 条也没有关节囊候选关联；还有混合连接需要按子关节进一步分类。这不是 116 个互不重复的解剖关节数量。
3. 完整纤维环、髌韧带主体、部分小连接组织还未建立可靠模型。未把缺失的源模型解释成这些结构不存在。
4. 286 个韧带目前依据源父级建立区域目录，尚未逐条标定足印。组合韧带／囊尚未全部细分；18 个拆缝候选仍待判断真实连续性。
5. 全身静态附着和穿插审核尚未完成。当前没有据此开放关节运动。

逐连接缺口见 第二阶段完成度检查.json。此检查覆盖既有 205 条连接登记，列明内部组织、囊、区域韧带候选和滑膜状态；不是专家解剖验收。
