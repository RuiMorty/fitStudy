# 全身分层制作执行单

更新：2026-10-12。状态：制作计划，未新增解剖模型。本文件作为执行顺序入口，补充已有分区清单，不覆盖原有来源与审核记录。

## 主线

全身按层推进；局部验证用于确定该层标准，不意味着先把肘部所有肌肉做完再制作其他关节。每层依次经过：逐对象清单 → 来源与许可核对 → 同骨架配准 → 静态模型 → 网页分层交互 → 必要的运动检查 → 分项审核。几何、装配、运动和解剖审核分别记录。

| 批次 | 交付范围 | 完成条件与依赖 |
|---|---|---|
| 0 当前底座核对 | 现有骨对象、骨性标志、装配问题台账 | 200 基础对象加 6 听小骨试装可显示，不等于 206 骨已审核；尾骨、听小骨、左髋及双踝问题保留；逐区域确认能否承接下一层 |
| 1 关节面与内部组织 | 全身关节软骨、适用部位的盘、半月板、唇、椎间盘等 | 先验证右肘软骨与骨面配准，再按区域补齐本层；颅缝、联合等使用其实际组织类型，不套滑膜关节模板 |
| 2 连接与稳定组织 | 关节囊、滑膜、韧带、骨间膜 | 附着区域、囊壁边界及关节腔关系可查；关节轴和运动约定同步建立，不用静态无穿插证明动态准确 |
| 3 深层肌肉系统 | 深层肌腹、相关肌腱/腱膜 | 从已核对骨面建立附着；相关筋膜、滑囊和绕行结构如影响路径，同步制作 |
| 4 中浅层肌肉系统 | 其余肌腹及相关肌腱/腱膜 | 检查跨关节路径、层间空间与整块肌腹变化；不把运动方向等同于激活状态 |
| 5 筋膜系统完善 | 各区浅深筋膜、肌间隔、支持带等 | 复核与肌肉/腱膜连续性；已随肌肉制作的结构复用同一 ID，不重复套壳 |
| 6 局部软组织完善 | 尚缺的滑囊、腱鞘、脂肪垫等 | 解释局部空间；影响前序建模者提前进入对应批次 |
| 7 拓展观察层 | 主要神经血管、皮下组织、皮肤 | 按教学用途定义分支范围；不承诺穷尽所有微小结构 |

显示层与制作批次是独立字段。用户可单独开关组织类型，不能把显示顺序冒充全身统一的内外解剖层次。

## 全身资源核查入口

先查看 [全身关节层清单](全身关节层清单.md) 与 [资源核查报告](资源核查与制作入口.md)。右肘仅作为覆盖区域标定样板，不代表制作范围只限右肘。

## 首个局部方法验证批次

1. 沿用主骨架坐标，锁定右肩胛骨、肱骨、尺骨、桡骨作为参考；不另造一套骨头。
2. 使用 `右肘首批结构.json` 建立骨面区域和关节结构资源映射。先查同源资源，缺项再评估补建；不得仅以名称相同认定匹配。
3. 先核对右肱骨滑车、小头，尺骨滑车切迹、桡切迹，桡骨头关节凹及环状关节面。代表点不能代替完整覆盖边界；对象中心不能当作关节轴。
4. 先做六处软骨覆盖区域的静态模型。覆盖区域是制作单元，最终网格可按真实连续性合并，不宣称六块彼此分离的软骨。
5. 在独立关节层中接入，提供点击、透明、隐藏、隔离和精确聚合。先完成静态核对，不急于加运动或肌肉。
6. 通过该层样板检查后，整理其他区域逐对象清单并扩展关节层；右肘关节囊与韧带可穿插推进，用于验证后续运动所需约束。

本批不设置未经核对的软骨厚度、附着坐标、运动轴或活动范围。参考文献需落实到结构对应页码/图号或影像切片，方可改变审核状态。

## 台账最低字段

唯一 ID、中文名、左右侧、组织类型、制作批次、显示组、所属关节、所属/相邻骨、依赖 ID、资源文件、来源及许可、附着或覆盖区域、坐标约定、几何状态、装配状态、解剖审核、运动审核。

## 每批交付

可编辑 Blend、网页 GLB、结构台账、来源/许可记录、静态与必要动态检查结果、已知问题。网页通过不等于解剖审核通过；示意结构必须保持示意标签。
