# 肩部韧带 · 第一轮清单与审核说明

## 本轮范围

肩部（盂肱、肩锁、喙锁和肩胛相关连接），不包括胸锁/肋锁组。Z-Anatomy 现有 11 类、双侧 22 个独立对象，不等于已覆盖所有分束、变异和组织融合边界。

## 操作与文件

从主页面“组织层”中的“肩部韧带审核”进入，或打开 http://127.0.0.1:8771/shoulder-review/ 。沿用主项目 npm start，本轮没有部署。

- `shoulder-review.blend`：可编辑场景，原版和修形候选同坐标共存。
- `shoulder-review.glb`：6 个参考骨对象 + 22 个源版 + 22 个修形版，共 50 个对象。
- `catalog.json`：11 类双侧附着、形状、参考原文和模型对照。
- `geometry-audit.json`：几何初筛、边缘候选及修形位移。
- `build_models.py`：从未修改的 Startup.blend 重建候选。
- `build_catalog.py`：从已存参考文本生成资料，验证引用原文存在。

## 本轮修形的明确边界

保留源表面边界，细分网格、内部平滑、加入不超过 0.55 mm 的示意截面弧度和边缘渐薄；浏览器提供弱纤维法线与柔和光照。参数用于展示，非组织测量，不能据此推导刚度或应变。没有用最近骨面自动修改附着。原始 Startup.blend 及主场景肩部模型未被替换。

A/B 三维标记取自表面主轴两端的边界候选，并非经过骨性标志标定的真实起止足印。正文的附着区域 A/B 不与这两个几何点自动对应。最近骨面距离仅用于筛查。

相交初筛使用顶点与最近表面法线关系，凹面可能误报，未作为闭合体穿透检测或解剖通过依据。保留疑点以免重演“消除穿模但附错骨”的问题。

## 暂未补建与原因

- 盂肱下韧带复合体：源对象存在，但前束、后束和腋隐窝未独立分区；下一步须结合囊、盂唇后再拆分。
- 喙肱韧带及肩锁囊韧带：现有对象不代表全部分束和融合边界已建好。
- 喙盂韧带：本次源清单未见独立对象；文献描述存在变异及辨识差异，列为研究候选，不强行补一条标准带。
- 本轮范围是肩部韧带；胸锁、肋锁连接另成一组，不计入此处 11 类。
- 视觉修形版只改善网格分辨率、边缘厚度和材质，没有校准所有附着，也不作为运动绑定成品。

现有 11 类均有源模型，因此本轮未另造替代韧带。喙盂韧带虽有文献但存在变异及识别差异，目前没有可靠的个体足印标定；作为缺口保留，不根据邻近模型端点随意连线。前后束及腋隐窝需要结合原关节囊/盂唇复核后拆分。

## 证据状态

8 类已取得支持概括性附着/走行的原文；盂肱上、肩锁、肩胛下横 3 类明确标记资料待补齐。全部 22 个三维对象仍未解剖验收。检索全文和来源链接保存在 references/ 与 catalog.json。参考文献不等于模型足印已经准确。

## 来源与许可

模型来自本项目固定的 Z-Anatomy 源数据，其署名与许可沿用上级 z-anatomy-candidate/README.md。文献仅用于事实核查与短摘录；未把论文配图改制为模型贴图。网页为独立本地审核工具。

## 骨性标志标签

已加入 9 类双侧 18 个中文标签，数据在 landmarks.json。build_landmarks.py 从源模型的文字引线提取最终求值端点（包括修改器），而非韧带网格端点。所有端点距对应骨面小于 0.1 mm；该检查验证配准，不代表标志范围或韧带足印已验收。

默认显示当前韧带相关标志，可按名称筛选或查看全部已收录标志。引线透视显示，旋转观察确认表面位置。选择名称不移动相机；“定位标志”平移视图中心并保持缩放。隐藏所属骨时同步隐藏标签。
