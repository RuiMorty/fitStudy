# 画布外 UI · 第二版

范围：只调整 index.html 中的页头、目录、侧栏及外层布局，新增 src/ui-layout.css。画布内 HTML 和 src/app.js 经 SHA-256 对比保持不变；未编辑模型、光照、相机或交互逻辑。布局容器尺寸改变会触发现有响应式画布 resize。

方向：浅灰白面板、深灰中文文本、墨绿色常用操作、低饱和琥珀色审核标签。中文采用本机 PingFang SC / 系统无衬线回退，不引入在线字体。选中结构先于设置显示；光照、听小骨试装和审核说明使用原生 details 折叠。

依据：ui-ux-pro-max 的 Minimalism & Swiss Style 检索与通用可访问性规则。初次 design-system 输出包含营销/转化布局，未应用；设置折叠专项检索未得到相关匹配，此项为基于现有任务流程的界面判断。

检查：1440、1024、768、390、375 像素宽度无横向溢出；选择、隔离、显示全部、折叠光照及试装控件可用；减少动态效果模式生效；浏览器无报错。手机为桌面浏览器尺寸模拟。

回退：ui-before-layout-v2.zip 保存改动前 index.html、src/style.css 和 src/app.js。恢复 HTML 即不再加载新增 UI 样式；不要覆盖之后独立更新的 app.js。
