# 肘部韧带审核

本地地址：http://127.0.0.1:8771/elbow-review/ 。沿用上级 npm start，无部署。

已有 4 类双侧 8 个源对象；与 6 个参考骨一起提供 22 节点的源版/显示版数据。界面只显示优化版，源版保留于文件。未验收附着足印及运动。

| 韧带 | 文献附着一侧 | 文献另一侧 |
|---|---|---|
| 右肘尺侧副韧带 | 肱骨内上髁；这是肱尺连接束的概括性起侧描述。 | 当前资料概括为尺骨冠突区域；不能用这一处代替后束、横束的全部附着。 |
| 右肘桡侧副韧带 | 肱骨外上髁。 | 远端纤维与桡骨环状韧带融合，并与邻近旋后肌、桡侧腕短伸肌纤维相连。 |
| 右方形韧带 | 尺骨旋后肌窝上部、桡切迹下方邻近区域。 | 桡骨颈，位于桡骨粗隆近侧。 |
| 右桡骨环状韧带 | 尺骨桡切迹前缘。 | 尺骨桡切迹后缘；主体环绕桡骨头。 |

## 尚待处理

- 尺侧副韧带：前、后及横/下方束尚未独立划分，精确附着未验收。
- 桡侧副韧带不等同于外侧尺副韧带（LUCL）；源名称清单未检出独立 LUCL 对象。
- 环状韧带与桡侧副韧带的融合、关节囊及完整外侧复合体尚未共同校准。
- 颜色仅是沿骨面扩展的定位范围示意，不是经过文献描边的骨性边界，也不是韧带足印。
- 当前不提供关节动画，避免把未核准附着带入屈伸或旋前旋后。

## 颜色范围

8 类双侧 16 个骨性标志。标志位置来自源文件最终求值的引线；着色沿实际骨表面网格距离扩展，并以柔边淡出。扩展半径是定位展示参数，不能代表文献确认的骨性边界，更不能代表韧带附着区。颜色与标签一一对应，开关独立。

## 文件

elbow-review.blend / .glb：可编辑源与网页模型。catalog.json：资料对照。landmarks.json：源标记。landmark-regions.json：示意面范围。geometry-audit.json：几何初筛。build_models.py / build_catalog.py / build_landmarks.py：重建脚本。面范围生成使用 ../joint-review-common/build_regions.py。

共享审核脚本在 ../joint-review-common/。点击韧带不自动移动相机；近看和定位为显式操作。

## 桡侧副韧带连接端显示修形

当前页面使用 elbow-review-contact.glb 与 geometry-audit-contact.json；可编辑文件为 elbow-review-contact.blend，重建脚本 refine_contact.py。原 elbow-review.blend / .glb 保留。

仅双侧桡侧副韧带的显示网格改变。上端向对应肱骨贴合，下端沿环状韧带外表面延伸、平滑，并逐渐减薄；贴面微间隔用于避免共面闪烁。没有透明渐变。尺侧副韧带与其他模型不改动。单条查看桡侧副韧带时同时显示环状韧带，便于判断连接。

此为局部显示修形，端区范围是基于当前网格的展示控制，不是精确解剖足印。当前骨面最近法线初筛无大于 0.5 mm 的疑似深部相交样本，不代表完整碰撞或运动验收。旧 PCA 边缘候选不再用于修形后的桡侧副韧带。

## 当前附着修整版本

页面现使用 elbow-review-assembly.glb / geometry-audit-assembly.json；编辑文件 elbow-review-assembly.blend。repair_attachments.py 从保留的原始审核文件出发，生成中间 assembly-base，再调用 refine_contact.py 更新桡侧接合。原模型及先前 contact 版均保留。assembly-notes.json 保存显示范围说明，assembly-checks.json 记录候选接合端距离；不是文献测量的足印。

- 环状韧带：从源控制网格识别前端 [2,17,3]、后端 [14,23,15]，沿源走行重建平滑曲面，仅两端邻近段向对应尺骨贴合。中间环绕桡骨，不接到肱骨。
- 尺侧副韧带：使用源肱尺侧 [3,2]、[6,7]、[0,1]、[4,5] 四排控制点形成局部候选带；未确认的桡侧延伸不纳入派生显示。没有把它冒称为完整三束复合体，完整分束与精确足印仍待核准。
- 桡侧副韧带：使用更新环状韧带作为下端接合支撑，仍保持独立对象。
- 网格端排与指定骨面的间隔约 0.04 mm 为防共面闪烁的显示参数，不代表真实组织间隙。
- 当前完成的是静态装配修整；不构成运动、真实力学或专业解剖验收。
