# 肘部骨骼与韧带运动候选 v2

主页面右侧的「关节运动」进入。支持左右肘、0–120° 屈曲增量、播放/暂停、复位、候选轴开关和退出。退出恢复原骨骼姿态及进入前相机。仅审核入口移至外观工具下方并默认折叠；关节局部查看和组织显示开关保持上方展开。

## 当前实现

- 使用现有 Z-Anatomy 上肢骨架。肱骨固定；同侧桡骨、尺骨及手部 29 块骨构成刚性链，保持相互位置、比例。当前不做前臂旋前旋后。
- 每帧由原始位置、四元数计算，不累计旋转误差；运动与结构展开互斥。
- 轴从同源内外上髁初始化，结合滑车标记面投影圆与肱骨小头球心拟合。`elbow-axis.json` 记录位置、方向及拟合来源。不是已核准的瞬时运动轴。
- 0°仅代表源模型装配姿态。120°是此次试验上限，不是正常或个人临床活动范围。
- 默认在全身中展示肘部运动，可切换局部查看；切换保留当前角度。「显示韧带」可独立开关。运动不改变组织颜色。
- 双侧尺侧副韧带、桡侧副韧带沿用审核模型，添加附着候选约束与形态插值。前者连接肱骨与尺骨；后者连接肱骨与环状韧带，不错误绑定到桡骨。
- 环状韧带与方形韧带在本次纯屈伸中随前臂整体移动。可确定全部附着骨均属于运动链的腕、手及前臂组织随链移动；未建模的跨关节组织不作虚假的静态展示。
- 尚未实现肌肉运动、软骨接触和组织应力计算；本版不是所有关节的全身动画。
- 全身固定旋转中心仍保留；进入时用侧前方视角展示屈伸。
- 手机运动模式显示全宽画布与底部控制区，退出恢复原布局。

## 验证与限制

`node qa/check_elbow_ligaments.mjs` 加载实际 GLB，验证双侧 0、2.5、30、62.5、90、117.5、120° 的附着候选随动、非刚性变形、全身/局部切换及退出后原对象与变换恢复。数值报告为 `qa/elbow-ligaments-validation.json`；误差仅衡量程序对已选候选的绑定，不代表解剖足印精度。

附着候选由与指定目标表面的距离（不超过 0.8 mm）等几何条件选取，尚未逐一通过解剖审核。尺侧副韧带仍不是完整三束复合体。形态数据每 5° 一档，浏览器插值并对端部使用实际角度的精确变换。自由段采用有限骨表面穿入筛查；这不能证明所有连续帧、软组织之间及自相交均不存在。

`node qa/check_elbow_motion.mjs` 检查双侧骨链距离、不缩放、固定肱骨、精确复位和轴线清理。

`check_elbow_geometry.py` 使用当前资源清单的「上肢」文件，在双侧 0–120° 每 5° 进行三角面相交抽样。50 个姿态中，肱骨—桡骨与肱骨—尺骨未检出相交。详情见 `geometry-sampling.json`。这不检查真实软骨接触压力、表面间隙是否生理、连续帧所有三角面、个人活动范围或韧带约束，不等于解剖运动通过验收。

桌面实测全身/局部、播放/暂停、韧带开关、近看、左右切换、复位及退出后控制恢复；390×844 手机尺寸检查画布和控制区。截图位于 `qa/elbow-ligaments-whole.png`、`qa/elbow-ligaments-local120.png`、`qa/elbow-ligaments-mobile.png`。

## 重建

用 Blender 后台依次运行 `motion/fit_elbow_axis.py` 和 `motion/check_elbow_geometry.py`。浏览器运行逻辑在 `src/elbow-motion.js`，主页面状态协调在 `src/app.js`。原始骨网格不改写。

韧带数据由 `motion/build_elbow_ligament_motion.py` 读取 `elbow-review/elbow-review-assembly.blend` 和 `motion/elbow-axis.json` 生成。使用 Blender 后台运行该脚本，输出可编辑的 `elbow-ligaments-motion.blend`、网页用 `elbow-ligaments-motion.glb` 和 `ligament-deformation-audit.json`。源审核文件不改写。Blend 包含形态键和参考骨运动；GLB 包含四个可变形韧带网格，环状与方形韧带在网页中复用现有网格。

从本工作台目录运行 `python3 -m http.server 8771`，打开 `http://127.0.0.1:8771/`，点击「进入肘部运动」。仅本地运行，不涉及部署。

## 组织层控制

运动时骨骼、软骨/关节盘、关节囊、韧带和标记面的五个开关保持可用。上方“显示韧带”与下方韧带层同步，切换不重置角度。只显示已确定可固定、可随骨链移动或已有变形绑定的组织；跨运动骨与固定骨而未绑定的组织仍不显示，不能将静态关节囊假装成随动模型。局部视图按肘部连接目录进一步筛选。退出保留用户调整的层开关。

## 肘部韧带后续修形顺序

当前目录每侧为尺侧副韧带、桡侧副韧带、环状韧带、方形韧带四个对象。尺侧副韧带存在，但源对象未分束；不能凭整体对象名称认定后束已完整，也不能断言后束完全没有。优先核对源网格覆盖的足印和纤维区，再决定分束或补建。

1. 尺侧副韧带：先核对现有网格的前后覆盖与各束附着，避免把整片远端绑定到同一冠突区域；宽附着区采用面约束，主体保留扇形纤维走向。
2. 桡侧副韧带与外侧复合体：保留与环状韧带连续过渡；当前目录无独立尺侧外侧副韧带对象，是否包含在组合网格须先检查，不能重复叠加一条。
3. 环状与方形韧带：检查真实附着端贴合、边缘厚度与交接处，避免整圈环状韧带粘在桡骨上。
4. 每项均检查静止、中间和大屈曲姿态；只在已经确认的附着面小幅埋入，不能把自由段穿骨用作接触优化。形状与运动调整后重新导出、验证。

这些是下一阶段修形要求，本次开关修复未擅自改动韧带解剖网格。
