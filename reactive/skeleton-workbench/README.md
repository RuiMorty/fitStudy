# 骨架结构研究 · 0.1 来源审查版

独立工作目录，不改变既有肘部样板和课程，不部署。此次继续任务的产物是可操作的来源审查场景，不是已准入的完整 206 骨模型。上一轮资源审查结论仍然有效。

## 启动

在此目录运行 `npm start`，打开 http://127.0.0.1:8771 。也可以运行 `python3 -m http.server 8771 --bind 127.0.0.1`。不要通过 file:// 打开。

网页提供旋转缩放、真实网格点击、中文搜索、身体区域选择、隐藏、单骨隔离、近看、区域内展开及精确聚合。聚合不重置相机；正面/背面/侧面与适应视图独立操作。导线只连接原始位置，不代表解剖附着或关节轴。

## 文件

- `assets/skeleton-review.blend`：199 个独立命名骨对象，按解剖区域分组，单位米，可编辑来源主场景。
- `assets/region-0.glb` 至 `region-5.glb`：颅骨、舌骨、脊柱、胸廓、上肢、下肢；总计约 31.75 MiB，1,837,147 三角面。
- `data/structures.json`：完整 206 项清单、199 项可用状态、源哈希、装配位置和审核状态。
- `data/connections.json`：205 条连接/连接组登记，数量不是人体关节数，关节轴与活动范围尚未校准。
- `blender/build.py`：从相邻 `skeleton-plan/source-audit/raw` 重建场景。运行 `blender -b --python blender/build.py`；需安装 Blender。重建会覆盖本审查版导出文件，请先另存手工修改。
- `qa/`：浏览器验证脚本、桌面/手机尺寸截图、报告；`check_assets.py` 检查 GLB 结构数量、面数和源文件哈希。

## 加工内容与坐标

全部资源使用 BodyParts3D 3.0 同一固定提交 f0eeb6e843380cfe6b83797cf8c3e1af74de5e61。

原始毫米坐标 [x,y,z] 统一转为 Blender 米 [x,y,z]，导出 glTF 后为米 [x,z,-y]。原始世界位置保持不变。对象原点设在各自包围盒中心，网格作反向平移补偿；这些原点不是关节中心。胸骨三段合为一个语义对象；平滑法线只影响光照，没有细分、补洞、删碎片或修形。网页展开通过额外位置偏移实现，每次聚合直接恢复保存的装配位置，不累计运算误差。

源文件仍在相邻 skeleton-plan 中，未修改，哈希核验通过。网页按 6 区域文件顺序加载，当前最终仍全部驻留；还没有按需卸载或生产级 LOD。主场景保存的是本次获得的降面源网格，不能称为原始扫描高精模型。

## 展开方式比较

侧栏“展开方式”提供原版区域散开、前后分层、按部位整组拉开、沿连接逐段拉开、选中骨及相邻骨局部展开、单块移出、全身向外扩散。切换方式、拖动间距和聚合均不调整相机，不缩放或旋转骨骼。超出画面可手动缩放或点击适应视图。

局部模式根据当前骨关联的连接登记选取相邻骨，连接组可能包含多块骨，并不等于全部都是直接关节面接触。沿连接模式将登记图转为展示用生成森林，只是分解路径，不用作运动绑定或关节轴。分层模式按原始几何前后位置分离，不是组织学分层。按部位模式保留各组内部的相对位置。所有模式位移从原始装配位置重算，复位不累计误差。

## 自由定位与放大
