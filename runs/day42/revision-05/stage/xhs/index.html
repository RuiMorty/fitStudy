卧推设置：先把支点找稳

闭合握杠、上背稳定、臀部贴凳、脚掌着地。拱度和握距以可控制、舒适为先。

  • 器械与出杠

    • 检查平凳、架柱、挂钩与安全杆是否固定。
    • 两侧负重相同；挂钩高度应便于保持上背位置出杠。
    • 先用空杆检查出杠、触胸与回架，不照搬别人的孔位。

  • 握法与手腕

    • 拇指绕杠闭合握持，两手到杠中心等距。
    • 杠靠掌根；触胸附近从正面看，前臂大致竖直。
    • 握距以肩腕舒适为先，避免杠落指根、手腕过度后折。

  • 把支点稳住

    • 肩胛适度后收，头、上背与臀部保持贴凳。
    • 双脚稳定着地，腰背保留舒适拱度，不追求极端起桥。
    • 轻杆演练几次；若要抬臀或腰部明显不适，先调整设置。

卧推过程：触胸不弹胸

图示推起顶部：杠在肩部上方附近稳定。下放至适合自己的胸部触点，再平顺推回；不强求唯一轨迹。

  • 下放与触胸

    • 出杠后先在肩部上方附近稳定，再平顺下降。
    • 常在胸骨中下段附近轻触，触点随握距和个体条件调整。
    • 不弹胸、不压颈；肩痛时不强求触胸或更大范围。

  • 推起与腿部驱动

    • 由胸部触点平顺推回肩部上方附近，不强求唯一轨迹。
    • 脚持续对地施力，帮助保持上背支点与全身张力。
    • 臀部留在凳面，不在最难处突然抬臀或蹬地弹杠。

  • 顶部稳定，再回架

    • 顶部稳住后再继续，配合呼吸，不整组持续憋气。
    • 结束时确认两侧挂钩，与保护者按约定口令回架。
    • 两端都落稳后再松手；用侧面视频复核轨迹和支点。

卧推保护：口令先说清

保护者站在举者头端，须受过训练并具备控制能力；安全杆也要按本人姿势实测。

  • 开始前说清楚

    • 保护者站在举者头端，须受过训练并有控制负荷的能力。
    • 约定次数、是否协助出杠、求助口令与立即介入的情况。
    • 正常重复不持续托杠；未经训练的人不要临时补位。

  • 安全杆要实测

    • 左右等高，并按本人凳高、体型与卧推姿势调整。
    • 正常无痛动作不应碰杆；失败时降低拱度，应能被承接。
    • 先用空杆检查空间，不把固定孔位当作所有人的标准。

  • 介入与结束

    • 举者求助或杠明显失控时，及时协助控制并共同回架。
    • 确认两端挂钩都承稳，再松开双手。
    • 缺少合适保护者或安全设施时换方案，不独自强试极限。

传统划船：髋折，背稳

先维持俯身，再后移上臂、屈肘拉起。蓝线示躯干方向，箭头示髋后移、下放与拉起。

  • 先建立俯身

    • 膝轻屈、髋后移，用髋铰链形成俯身。
    • 脊柱保持自然曲线，选择肩腰舒适、能维持的躯干角度。
    • 传统划船常在每次之间悬空，不必强求躯干完全水平。

  • 再完成拉动

    • 从手臂伸长开始，上臂后移并屈肘，拉向下胸至上腹附近。
    • 肘路与握法改变肩部动作，不强行夹肘或极端外张。
    • 肩胛随动作自然移动，控制下放，不耸肩硬挤。

  • 看质量，及时回退

    • 观察躯干倾角是否大致一致，不靠反复挺髋或甩腰补重量。
    • 从侧面看腰背控制，从后方复核杠端是否反复倾斜。
    • 若姿势越来越难维持，先减重、减次数或改用胸托划船。

Pendlay：落地后重新准备

每次从地面静止起拉，躯干通常接近水平。它与传统悬空划船的区别不只是速度。

  • 地面起点要合适

    • 每次从地面静止起拉，躯干通常接近水平。
    • 髋部折叠、背部稳定；轻片太小时可用稳定垫高调整杠高。
    • 不要为够到地面而反复圆腰，也不硬套别人的起始高度。

  • 回地之后重置

    • 拉向下胸或上腹附近，再控制回到地面。
    • 杠片停稳后，重新建立足底支撑与躯干张力。
    • 向上可有加速意图，但不借反弹、猛挺髋或耸肩完成。

  • 和传统划船怎么比

    • Pendlay每次回地重置；传统俯身划船常连续悬空。
    • 两者的躯干角度、停顿与负荷需求不同，不直接比公斤数。
    • 在相同变式、节奏与活动范围下，观察自己的重复质量。

力量翻：三段连成一次动作

一次拉 → 过渡后二次拉 → 钻杠接铃。它是全身爆发动作，不是手臂弯举。

  • 一次拉：杠近身

    • 起始位保持双臂伸直、躯干稳定。
    • 用腿推动地面，肩与髋协调上升，杠经过膝附近。
    • 不抢先弯举，也不先把髋猛抬高。

  • 二次拉：衔接加速

    • 杠过膝进入过渡后，协调快速伸髋、伸膝。
    • 让杠靠近身体，不用髋把杠撞向远处。
    • 伸展与后续钻杠相连，不模仿夸张后仰的单帧姿势。

  • 接铃：前肩承托

    • 转肘到杠下，屈髋屈膝缓冲，以前肩平台接铃。
    • 力量翻通常在大腿高于水平时接住；手指辅助，别靠手腕托重。
    • 先学前架与失败处理，负重练习需合格教练现场指导。

推拉配对：别把肌肉当开关

卧推偏水平推，划船偏水平拉。橙区仅示意参与区域，不是精确解剖图；稳定需要全身协作。

  • 卧推：肩与肘一起推

    • 向上阶段包含肩水平内收等动作与肘伸。
    • 胸大肌、前三角肌和肱三头肌共同参与。
    • 上背、肩胛周围肌群及躯干腿部提供支撑，不是只练胸。

  • 划船：上臂后移，屈肘拉

    • 包含肩伸或水平外展、肘屈与肩胛运动。
    • 背部肌群、三角肌后束及肘屈肌群共同参与。
    • 肘路和握法会改变需求；髋部与躯干保持俯身稳定。

  • 拮抗关系不是开关

    • 肘伸与肘屈方向相对，不代表另一侧肌肉完全关闭。
    • 同一肌肉的角色随关节、角度与阶段改变，稳定常需共同收缩。
    • 橙色区域仅作示意；泵感不能量化激活，也不能诊断肌肉失效。

左右有差：先排除假象

杠端倾斜只是现象。图中蓝绿色标线比较握点到中心的距离；先查设置、视角与疲劳，再复核。

  • 先排除设置与视角

    • 核对两侧负重、握点和器械高度，身体放在中间。
    • 固定正面或后方拍摄角度，避免斜拍制造倾斜假象。
    • 看数次轻负荷重复，不凭一帧就判断哪边弱。

  • 保持条件，再比较

    • 统一负荷、节奏、活动范围与休息，减重后跨组复核。
    • 必要时用合适的单侧动作观察，留意顺序与疲劳影响。
    • 记录杠端、肘路与躯干旋转，不把某个差值当作通用诊断线。

  • 调整训练与停止信号

    • 先让动作恢复稳定，不自动给弱侧加倍组数。
    • 单侧练习可从控制较弱侧开始，以其稳定次数与范围约束另一侧。
    • 疼痛、麻木、突然无力或持续加重时，停止相关负重并进一步评估。

实操对照：卧推与划船

图中用肘伸与肘屈提示推拉方向。把动作、参与肌群和稳定提示写成两行，再用一次轻负荷练习复核。

  • 先写卧推这一行

    • 动作：肩水平内收等动作＋肘伸。
    • 参与肌群：胸大肌、前三角肌、肱三头肌等。
    • 稳定提示：臀部贴凳、脚稳住；在合适保护条件下轻杆练习。

  • 再写划船这一行

    • 动作：肩伸或水平外展＋肘屈，并伴随肩胛运动。
    • 参与肌群：背部肌群、三角肌后束、肘屈肌群等。
    • 稳定提示：髋折住，再拉肘；躯干不过度起伏。

  • 最后做一次复核

    • 空手演示肘伸与肘屈，说明方向相对不等于肌肉互相关闭。
    • 选一个可观察指标，如臀部贴凳或划船躯干角度。
    • 一次只改一个条件，用相近条件比较下一组是否更可控。
